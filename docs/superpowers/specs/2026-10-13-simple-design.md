# Alur inti IzinHukum

Klien melihat detail layanan dan paket, checkout mencatat order awal, WhatsApp dipakai manual. Admin menerbitkan invoice setelah kesepakatan, mencatat pembayaran terverifikasi dan pengeluaran, serta membaca laporan kas. Tanpa gateway, AI, CRM, campaign, mitra, kupon, LMS atau portal klien. Data/migrasi historis dipertahankan. Domain admin opsional memakai host yang sama dengan path /admin. Bukti transfer dan dokumen klien ditukar melalui WhatsApp.
